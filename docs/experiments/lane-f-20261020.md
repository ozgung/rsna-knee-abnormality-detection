### Round 1 teacher: four hash-fold S6 fits on labels v3

- **Pool and labels.** `targets_V3_h4_all.csv` (sha256 998ed54e…) = Lane B's `targets_V3_all.csv` (8d2ef527…) with the `fold`
  column rewritten to the R6/R7 hash rule `sha1(uid)[:8] % 4` (`scripts/lanef/make_hash4_targets.py`; every other byte
  identical, same 840,680 B, `check_targets.py` CHECK_OK). The trainer reads folds from this column, so its folds are exactly
  Lane B's fold ids (the rule matched all 4,349 Lane B out-of-fold rows). Non-gold hash-fold sizes 1,029 / 1,135 / 1,118 / 1,067
  (4,349 rows; the pool after the 4 quarantined rows is 4,345). Gold-58 rows keep fold −1 and are never trained on.
- **Recipe.** `vm_train.sh` (1ebfdef1…, nartaa's S6fall run_config: convnext_small from the ImageNet-22k init, crop 288,
  64 windows, batch 2, lr 1e-4, wd 0.05, no EMA, no flips) with `--folds 4 --only-folds k --epochs 12 --eval-stride 1
  --seed-base 42`; trainer `compact_train_s6v2.py` 12e430a3…. Never an all-data checkpoint as init (they saw every fold).
  One fold per session (`scripts/lanef/vm_fold_boot.sh` → `vm_fold_fit.sh`, backups `vm_bk_fold_ckpt.sh`).
- **OOF columns.** The trainer's `--only-folds k` run predicts the held-out hash fold k with the fold-k model (eval stride 1,
  pixel cache, the same v4/320 windows the deployed compact_infer path renders) into `partial_oof_E_prior_s42.npy` (rows of
  other folds are zero and are never used), and gold-58 with the same model into `partial_preds_E_prior_s42.json` (the trainer
  divides the gold logits by K = 4; the analysis multiplies back). `oof_columns.csv` = the four fold-k rows stacked
  (uid, fold, 12 logits, 12 probabilities); `gold58_columns.csv` = per fold model logits and the 4-model mean logit.
  The `partial_` outputs are used only fold-wise, never as a full OOF array.
- **Metric and comparison (fixed).** Truth = `labels_v1_blend >= 0.5` on the pool; macro = mean of 12 per-target AUCs;
  paired study bootstrap 2,000 draws, seed 42 (`knee.paired_validation._auc_draws`, `resample_counts`), identical to Lane B.
  Read-out: own OOF macro per fold and pooled (per-fold score scales are mixed in the pooled number, as in Lane B); paired
  Δ against Lane B's R6-flip (0.9066) and R7-plain (0.9051) single-fold columns on the same studies, and against
  ½ rank(R6 flip) + ½ rank(own). Gold-58: the four fold models' mean logit, read once (the trainer's end-of-fit prediction),
  logged as exposed.
- **Kill rules.** Epoch-0 loss > 0.55 kills a fit (V2-all 0.5106; a 3/4-pool fit with the same bias init is comparable).
  A fold fit not started by Oct 21 02:00 is dropped and the teacher uses the available folds (documented as partial coverage).
