`scripts/build_own_model_submission.py` accepts a fresh destination, slug, `--rehearsal-build`, `--rehearsal-report` and `--rehearsal-csv`. It rejects any subset or non-PASS result before packaging. The completed rehearsal must qualify ordered folds 0–4, all 25 raw/corpus slot comparisons, window/probability/repeat parity, strict SWA loading and existing reader stresses. Notebook, contract, definitions, scientific dependency closure, codecs, environment and visible CSV are hash-bound; the archived executable must match its exact reconstruction. Any scientific dependency change requires another rehearsal. The archived closure is checked separately from the added final runtime and metadata-reader modules.

The fresh private offline notebook attaches only the three ConvNeXt training kernels, codec dataset and competition. It embeds code and validated aggregate qualification evidence, never the training corpus, private identity membership, raw labels or visible IDs. Fitted run JSON files are hashed as provenance and never parsed during inference. The codec attachment contains unused public weights; these are not opened.

`knee/own_model_submission.py` preserves the rehearsal's frozen 44-slice 15–85% reader, fatal resource handling, exact extracted StudyWindows/RaptorClassifier, resolution 256, k_eval 16, ImageNet normalization, CUDA FP16, study batch 1, no TTA and ordered equal probability mean. Checkpoints are deserialized weights-only, checked for exact architecture/resolution/target order/SWA epochs and strictly loaded. CUDA and pinned inference packages are mandatory; no CPU fallback. Deterministic cuDNN and disabled TF32 match rehearsal.

Actual `test.csv` determines study coverage and order through the existing `read_test_contract` helper. The sample submission supplies its exact official header only: hidden reruns may retain the original three sample rows. Series metadata must cover exactly the actual studies with safe unique series IDs and exact official schema. One study is decoded and windowed at a time; per-study decoding caches are released. All five models remain loaded, bounding model memory independently of study count. This changes memory residency from the serial rehearsal; actual five-model memory remains unmeasured.

The timer starts before source extraction/imports and enforces the actual nine-hour platform limit, including setup and inference. Outputs are `/kaggle/working/submission.csv`, a copy under `own_model_submission/`, and an aggregate `operational-receipt.json` with hashes, counts, package/backend, elapsed time and memory. No IDs enter receipts or errors. Partial CSV remains a `.tmp` file on failure; the submission is published only after exact ordered coverage and finite probabilities in [0,1] pass.

A SHA256 fingerprint of the known ordered visible IDs triggers byte-exact CSV comparison with the five-fold rehearsal, using the same `.9g` formatting and fold ordering. An arbitrary hidden set of three studies does not trigger that comparison. No tolerance relaxation is implemented. Exact parity is required but not yet demonstrated for the production runtime.
