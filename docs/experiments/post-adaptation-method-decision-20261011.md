The next action is one 32-study CPU geometry qualification, not another training cycle.** Start with a fixed geometric crop so that the first result answers whether a simple center prior is adequate before building a learned localizer.

MCL loses 0.015949 with 20 positives, fracture 0.022108 with 52 positives. These two targets account for almost all the aggregate loss; the separate three-target damage rule is not triggered. This rejects the tested recipe, not all adaptation or a causally proven label-noise explanation. Keep the endpoint fixed; no endpoint, label, gold, target-wise fusion or blend rescue.

The public control already decodes native DICOM to 384 and takes central320 over the inherited 140mm crop. Its nominal field is about 116.7mm when the original crop is not clamped. Native zoom can change scale and retain source samples beyond this representation; it is not simply a remedy for the own models' 336 cache. An identical-box crop from the **public384** image is the relevant later detail control. Stored pixel spacing does not establish intrinsic resolution.

## First executable contract: centered native90 preflight

- **Population:** exactly32 studies from fixed fold0 training membership, excluding gold/quarantine, selected by SHA256 of `20261011:StudyInstanceUID`, ascending digest then ID. Freeze the private manifest before rendering. No report text, label values, model scores or development/gold outcomes. Report represented/missing geometry and slot strata; this small sample cannot establish population coverage.
- **Proposal:** one90×90mm square per selected series, centered at the physical image center of its median selected slice (lower median on an even count). Keep its in-plane physical center fixed across that series by projection onto each slice. Use native row/column directions; no anatomical reorientation, left/right compartment split, cross-plane registration or learned detector. Call this a geometric center prior until image review establishes anatomical containment.
- **Native path:** retain the exact public chosen source files, order, repeated-slice policy and masks. Capture bounded source pixels and full geometry **before** the existing140mm crop/384 resize; `study_lut`'s final volume alone cannot recover them. Reuse the existing per-series2/98 intensity transform, modality handling and MONOCHROME1 policy; do not compute new ROI percentiles. Resize the90mm rectangle to320 and quantize consistently. Preserve the original global96×384 volume and masks byte-for-byte.
- **Geometry:** use both PixelSpacing components and finite, valid IOP/IPP; map pixel centers to physical space, project the common center into adjacent slices, and derive row/column extents separately. DICOM defines row/column spacing and the patient-coordinate mapping in its [Image Plane Module](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.7.6.2.html). Detailed formula, tolerances and fixture requirements are in the review artifact.
- **Fallback:** a triplet crossing series/slot boundaries, missing or invalid geometry, inconsistent orientation, an out-of-bounds crop, or unavailable crop pixels uses its corresponding unchanged global320 triplet. Count the reason; do not silently clamp, invent spacing or pad the ROI. Preserve inherited global behavior for partial/missing inputs. Fatal resource errors still fail. If the global path is unusable, fail rather than invent a prediction.
- **Evidence:** private, identifier-free-in-filename contact sheets show full native slices with the90mm and inherited global boxes, the native crop, and the identical-box public384 crop. Review each selected series at its quarter/middle/three-quarter positions and every fallback/geometry anomaly. Retain raw identifiers and mapping only in the ignored private manifest. Record anatomical containment/off-center or non-joint anatomy, field truncation, source sampling, fallback counts, runtime, peak RSS and storage. Neither image similarity nor visual sharpness proves useful pathology detail.
- **Mechanical acceptance:** all32 memberships and exact global bytes/masks/window tensors match the pinned control; all normal/mirrored outputs repeat exactly; physical transform/extent fixtures pass; fallback is exact and reason-coded; no resource failures or hidden labels. A native triplet uses a common physical center only within a series. Mirror transformation is applied to the extracted uint8 triplet before channel normalization, following the inherited slot-specific rule.
- **Anatomical acceptance:** inspect all planned contact sheets, recording assessable and nonassessable views. Any assessable joint view with relevant central anatomy visibly clipped, or a confidently emitted crop centered away from the joint, blocks this center prior from model fitting. Do not silently exclude failures or resize the box after looking. A pass means only this small sample supports the crop proposal; it does not validate a detector, guarantee hidden-test safety or prove a classification gain. If review is unavailable, mark anatomical acceptance unverified.

Run privately/offline on CPU with one study and at most one source series resident; save no corpus cache or raw DICOM copies. Reuse existing decoding dependencies and synthetic geometry checks. Record actual runtime/resources; no assistant-imposed GPU reserve or time cap. This preflight neither trains nor establishes fresh CUDA prediction parity. No command exists yet: implementation must first provide its tested entry point and immutable run manifest.

## After that gate

If the center prior fails, use the failure evidence to design a genuine image-only localizer before training; do not broaden into a crop-size search on report AUC. If it passes, the next model comparison should use the frozen public encoder with matched global-versus-native-ROI specialist heads, identical view budgets, training labels/masks and fixed endpoints, while retaining the unchanged public global model as an explicit third control. Pin that separate fitting protocol before launch. This reduces repeated full-backbone weak-label fitting and makes source/view differences interpretable; it is not a promise that a frozen encoder understands zoomed anatomy.

Any proposed combination must be fixed prospectively and beat the unchanged public control, not merely the extra-global specialist. Preserve posterior/peripheral global coverage. Require exact image-only reload parity and measured offline resources before a candidate. Public-model exposure, report-component rather than complete patient grouping, and previously used gold persist: second-fold replication remains exposed development evidence. No local interval supports a hidden-score forecast.

Coverage changes remain the fallback hypothesis if localization is unusable, but publicK94 already samples the dense96 representation; more windows alone do not add anatomy. Distillation cannot supply independent validation from the same exposed public teacher. Generic384 bootstrap expansion and the own-family blend remain secondary to the stronger public baseline.
