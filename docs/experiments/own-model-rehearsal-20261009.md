Only visible CSV contains public testIDs. Scientific mismatch or runtime failure is preserved; no retries/tolerance relaxation.

Actual GPU inference, timing, memory and hidden-test behavior are unverified until parent launch. Passing this bounded rehearsal establishes eight-input execution and five-input parity, not predictive performance or full hidden-test robustness. The attached codec dataset contains unused public weights that are never opened. Source/run/checkpoint bytes and container/dependencies are pinned; modules are embedded without models/labels/identities.
