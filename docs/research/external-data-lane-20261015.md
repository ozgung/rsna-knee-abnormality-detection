## 0. Verdict

**No external-data training lane clears positive expected private-rank value for the Oct 22 final, so none is opened.** The two authors whose public weights define the frontier already ran both routes, and their own numbers bound the gain: nartaa attributes a sequential **+0.003** to 2,399 OAI knees (0.942 → 0.945) [literature, D/746792 via `docs/archive/handoff/claude-codex-log-20261009-20261012.md:40`], and heliosli's R7 with the fastMRI+ auxiliary task (0.949, four folds) is matched by nartaa's S6fall without it (0.950, all data) [literature, 0.957 scan §1.4]. Our best own model is 0.915 on fold 0 (K42, masked weak labels) [measured]; a component needs about **0.94** on the same fold to be worth a 0.3 rank weight beside Raptor's column (0.951 exposed), and the A′ gate needs a Raptor-column lower bound ≥ +0.0017 [measured, lane 3]. A +0.003 to +0.008 class gain cannot reach that, and the clock allows no iteration: every step from download to hidden run must succeed first time between Oct 15 and Oct 20 16:00 UTC. P(any option clears the A′ gate by Oct 20) is about **0.01–0.02 each, ≤ 0.04 for the best one** [estimate]; at 356 places per +0.001 and an expected gain of +0.0005–0.001 if it did, that is **5–10 expected places**, against the attention it would take from A′ (R224), provenance checks and selection in the same week. ## 1. What we hold, and the clock

**Assets** [measured from source text unless marked].
- **fastMRI knee DICOMs** (batch1 about 134 GB, batch2 about 30 GB; tar.gz [estimate]): about 10,000 clinical NYU knee exams, about five series each (coronal PD, coronal PD FS, sagittal PD, sagittal T2 FS, axial T2 or PD FS), **no labels**, distinct from the k-space cohort [literature, Knoll 2020]. The closest-to-competition external corpus available: multi-plane, fluid-sensitive, clinical referrals, one vendor/site.
- **fastMRI+** (MIT): 16,154 boxes on **1,172 coronal k-space volumes** (multicoil train 973 + val 199; `knee_file_list.csv` has 1,172 names), `knee.csv` columns `file,slice,study_level,x,y,width,height,label`; 974 volumes have findings, 198 none; one radiologist per image [measured, CSV counts]. The boxes reference the **k-space reconstructions** (`reconstruction_esc`/`reconstruction_rss`, 320 × 320 at 0.5 mm, about 36 slices at 3 mm, coronal PD or PD FS only), **not the DICOM batches**. To use them we must fetch singlecoil train + val (**88 + 19 GB**) or multicoil (931 + 192 GB) [literature sizes].
- **OAI** (individual NDA access since Oct 12): images are prepackaged by visit; scan-type subsetting exists through predefined queries, participant-level subsetting is "custom (limited)" and unverified; `downloadcmd` (`nda-tools`) pulls personal packages, 20 TB/30-day cap; community reports 2–20 MB/s from NDA S3 [literature]. MOAKS: `kMRI_SQ_MOAKS_BICL00` / `kMRI_FNIH_SQ_MOAKS_BICL00`, 600 FNIH knees; join by `V00MRBARCD` = DICOM `AccessionNumber` [literature]. - **Our stack:** `knee/raptor64_cache.py` builds a 64-slot, 336 px / 140 mm cache from competition DICOMs using `train_series.csv` plane/fluid labels [measured]; external DICOMs need plane/sequence derivation from headers first. Fold-0 in-distil: 12 epochs at 21–26 min/epoch on one A100 (about 4.5–5.5 h) plus K42 export [measured, it2–it4].

**Clock, backwards from the last allowed hidden run (Oct 20 16:00 UTC)** [plan of record]: rehearsal on 2×T4 Oct 19 (quota refreshes Oct 17; about 30 h/week) → Codex wiring of a new worker Oct 18–19 (about one working day, **the same day R224/A′ needs**) → full-data export ready Oct 18 morning → full-data retrain Oct 17–18 (5–6 h) → fold-0 read-out Oct 17 12:00 → fine-tune Oct 16 evening (5 h) → external pretraining Oct 16 (2–8 h) → external cache and label join Oct 15 → download Oct 15. A′ (R224) also consumes 0.2–0.4 h of A's 0.92 h runtime margin; a new own arm costs a further **+0.3–0.5 h conservative** (reusing the frozen 140 mm volume resized to 336, K42 windows, about 55k forwards on T4 × the 1.44 projection factor) [estimate], so it only fits if lane 3b's prefetch (parked, P2 CPU ratio 1.52 > 1.3) lands its one allowed fix as well.

## 2. The bar an external-data component must clear

1. **Own-fold level:** Raptor's fold-0 column is 0.951 exposed (about 0.949 true) [measured]; own in-distil 0.915. Lane 3 established that a 0.3 rank weight on an arm 0.06–0.09 below its host at correlation about 0.9 is negative in expectation; the brief's threshold of **≥ 0.94 own-fold** is where a 0.3 weight stops being a loss [estimate]. Required jump: **+0.025 to +0.03**, in one shot.
2. **Entry gate (pre-registered, unchanged):** fixed 0.3 rank blend into the Raptor fold-0 column must give a primary-target Δ with 95 % CI lower bound ≥ +0.0017; A′ then needs displayed(A′) ≥ displayed(A) on one hidden slot.
3. **Runtime:** conservative projection ≤ 8.3 h with R224 included.

Reference points for how much external data has bought the public authors on their own models (not ours): OAI → +0.003 sequential (nartaa, not ablated) [literature]; fastMRI+ aux at weight 0.3 → indistinguishable from none (R7 0.949 vs S6fall 0.950, confounded by folds vs all-data and labels) [literature]; our in-distil (teacher distillation on competition data) → +0.008 [measured], the largest own gain so far.

## 4. Is there a cheaper test than a full build?

Yes, and it is already done for two of the four options: the public ablations above are the cheap test. For the remaining question (does any external pretraining lift *our* CoAtNet recipe), a 1-day pilot is executable, but **a passing pilot still cannot reach the Oct 22 final**: the pass criterion that would justify integration (≥ 0.94 on fold 0) is +0.025 above in-distil, far outside what any pilot of this class has delivered, and the integration path (full-data retrain, Codex worker, prefetch fix, rehearsal, hidden slot) does not fit after Oct 17 beside R224. So a pilot is knowledge for the write-up and for the post-deadline lane, not rank. It should run only if the user wants to spend Claude time on it while Codex stays entirely on A′, and it must not touch the A/A′ sources, pins, quota or slots.

### 4a. Knowledge-only pilot (opt-in; pre-registered here; zero Codex time; no entry path)
